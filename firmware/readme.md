# FIRMWARE

This keyboard uses the qmk firmware i also have setup some keybindings that are pretty neat so this file also acts like a documentation for the keybindings

Ok now lets move on to the bindings 

```
Fn + 1 + b : puts the keyboard into bootloader mode 

Fn + 1 + c : reinitializes the keyboard's EEPROM

Fn + 1 + a : toggles autocorrect

Fn + 1 + super: toggles super key
```

personally my favorite mode the mouse mode 
this activates when you hold that "ma" key next to the enter key when you hold this you can control your cursor as if you were using a mouse 
using your keyboard 

```
           q w e
  capslock a s d f
```
these are the keys used to navigate

```
wasd are pretty self explanatory 
q is for scroll up 
e is for scroll down 
capslock is for button 1 
f is for button 2 
```
