made for hack club's [fabricate](https://fabricate.hackclub.com)

Its a keyboard with 78 keys i quite like the keyboard it took me some time but i am happy with it i mean its my first electronics project so i am quite 
happy with the final product 

It has these features
- 78 keys
- reprogram anykey anyway you like using the keymap.c file located in the firmware/keymaps/default/keymap.c
- 1 rotary encoder
- a 128 x 32 OLED display
- and you can also kinda use this as a mouse

## Inspiration 
I made this project because i was inspired by the [brew-keeb](https://github.com/geg-tech/brew-keeb) project of [geg-tech](https://github.com/geg-tech) i really liked his keyboard and i also wanted to make my own keyboard so 
i thank geg-tech for making an awesome project and giving me the inspiration to make this one!!
